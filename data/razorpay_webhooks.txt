# Razorpay Webhooks

## Overview

Razorpay Webhooks allow partners and merchants to receive real-time event notifications when specific transactions or onboarding events occur.

Webhook payloads are sent to a configured endpoint URL whenever subscribed events are triggered.

---

## Core Use Cases

Webhooks are used for:

- Real-time payment status updates
- Order payment confirmations
- Refund tracking
- Invoice status monitoring
- Payment link lifecycle events
- Fund account validation
- Sub-merchant onboarding updates
- Account status monitoring

---

## Webhook Setup Process

### Dashboard Configuration:
1. Log in to Razorpay Dashboard
2. Navigate to:
text Partner Dashboard → Settings → Webhooks 

3. Configure:
- Webhook URL (HTTPS recommended)
- Secret key for signature validation
- Alert email for failure notifications
- Active events to subscribe

4. Create webhook

---

## Security Requirements

### Webhook Secret:
- Used to validate webhook authenticity
- Ensures payload originated from Razorpay

### Best Practices:
- Use HTTPS endpoints
- Verify webhook signatures
- Store secrets securely
- Monitor failed webhook deliveries
- Implement retry-safe handlers
- Log event payloads for debugging

## Operational Recommendations

- Process webhook payloads asynchronously
- Validate every incoming request
- Implement idempotency to avoid duplicate processing
- Handle delivery failures gracefully
- Maintain audit logs
- Use alerting for webhook failures
- Reconcile webhook data with API fetch operations

## Reliability Considerations

- Webhooks can fail due to:
  - Endpoint downtime
  - Signature mismatch
  - Invalid SSL
  - Slow processing
- Always maintain retry-safe systems
- Ensure endpoint uptime
- Monitor webhook health continuously
